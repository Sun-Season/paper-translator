# 使用说明

## 服务配置

macOS 启动器读取 `QWEN_API_KEY`，未设置时弹窗询问。可用 `QWEN_MODEL` 和 `QWEN_BASE_URL` 覆盖默认服务。命令行读取 `OPENAI_API_KEY`，通过 `--model` 和 `--base-url` 指定兼容接口。视觉流程会向服务发送论文页图、文字和复核所需的成品页图。

旧版 DeepSeek 路径读取 `DEEPSEEK_API_KEY`，也支持工程根目录的 `.env.deepseek.local`。密钥文件不会提交到 Git。

## 输出选项

| 参数 | 用途 |
| --- | --- |
| `--format pdf / md / both` | 选择产物 |
| `--backend vision --layout auto` | 视觉翻译，跟随原稿栏式 |
| `--layout reflow` | 视觉后端强制正文单栏 |
| `--layout reflow-two` | 视觉后端强制正文双栏 |
| `--max-review-rounds 5` | 视觉审阅总轮数上限，允许 1～10 |
| `--no-visual-review` | 只运行程序验收 |
| `--dpi 400` | 插图栅格化精度 |
| `--out 目录` | 指定尚不存在的交付目录 |

其他导出选项包括 `--backend latex --layout reflow-two` 和 `--backend mupdf`。完整参数以 `python translate.py --help` 为准。

## 复用译稿

将 `paper.md` 和 `figures/` 放在同一目录即可复用译稿与裁片。

```sh
.venv/bin/python translate.py "/路径/原稿.pdf"   --vision-draft "/路径/译稿/paper.md" --out "/路径/新结果"
```

不指定模型时执行程序验收。指定模型后还会调用译稿复核及成品视觉循环，可能产生服务费用。

## 中文翻译要求

视觉翻译、文本层回退和段落补译共用一套要求。科研译文以信、达、雅为标准，保留原意，用自然的中文说明研究问题、方法和证据。

- **拆。** 先读完整段落。按意群拆开长句，找出主张、依据和限制。
- **调。** 按中文习惯重组语序。拆句后回查否定、条件、比较对象、范围和确定程度。
- **增。** 只补原文已明确的对象、范畴词和衔接关系。原文指代不清时保留歧义。
- **转。** 用具体的动词写清谁做了什么。术语先看语境，再统一译名。比如强化学习中的 *logged simulator transitions* 是「模拟器记录的状态转移数据」。

成品复核先对照原文核对术语、事实和限定条件，再连读译文，找出妨碍理解的语序或指代，并提出局部改写。

## 验收范围

程序检查已识别的题头、编号图表、子表、算法框、内部链接和可疑英文。视觉模型对照原稿与成品提出修改，执行器支持局部改文、补文、重裁图片，以及单栏／跨栏调整；表格按原稿矢量还原，不支持逐单元格改写。每轮修改后重新编译并检查，候选没有改善时保留此前版本。

模型判断可能出错，扫描稿、复杂合并表头、细小公式和跨页段落仍可能需要人工复核。程序检查通过不代表逐句翻译全部正确。

视觉循环把所有未解决的 major 语义问题都当作发布阻断项，并区分 `unfixable`（执行器试过但落不了地）、`evidence_insufficient`（未执行或无法定位）、`still_problematic`（改过但仍未改善）。只有轻微问题记入 `视觉待复核.md`、不阻止发布；“工具修不了”不再等于“已确认没问题”。`参考文献检查.json` 单独统计参考文献中仍为中文的条目；该文件为提示项，发现中文条目应重新翻译参考文献区，工具不会自动改写。

## 恢复任务

验收未通过时不会创建交付目录；候选、编译诊断和逐轮审阅保存在同名 `.job` 目录中。同名 `.job/task.json` 记录任务阶段和异常。保留 `.job` 目录后用原命令恢复，已完成阶段与验证缓存可复用。代码或参数变化时工具会拒绝复用原任务，应另建输出目录。清理 `.job` 会失去恢复和候选审阅材料，正式结果目录仍可独立阅读。
