# 维护与验证

## 执行流程

默认视觉路径由 `paper_translator.cli` 进入，`harness.job_runtime.Job` 保存阶段状态。译稿检查完成后，`harness.visual_agent` 调用 `harness.vision_harness`，由后者编排 LaTeX 生成与程序验收。视觉反馈通过受限执行器进入下一轮候选。

`config/layout_policy.py` 控制排版参数，`config/object_policy.py` 保存翻译和视觉审阅共用要求。原稿解析放在 `source/`，排版放在 `render/`。改变格式时应同时检查生成参数、程序验收和视觉提示是否一致。

`legacy/` 保留仍有实际调用者的早期实现。默认视觉流程也复用其中部分图形和算法解析函数，不能仅凭目录名称删除。

## 版式验收与发布

`harness/layout_audit.py` 将超过 1 pt 的 LaTeX overfull 警告、缺字和实际页外绘制作为阻断项。实际绘制检查临时扩大 PDF 画布，检查纸张外的墨迹，保留 PDF 自身的裁剪路径。`Job.publish()` 在复制交付目录前独立复验，并拒绝 `needs_review` 的程序或视觉报告。不能把“编译成功”视为验收通过。

渲染器在 `latex/` 中保留编译源文件、日志和所用图形，供定位越界。每个图块的对齐设置限定在自身作用域；普通正文显式恢复左右边距。原稿表格整块以矢量页嵌入，不做单元格重排；表题和表注仍翻译。表格识别同时考虑表题、横线及横向位置，并排表格按原稿几何关系成组。图组恢复区分同一图的子图与各自带图注的并排图。

视觉循环将未执行动作的原因传回下一轮，不再因第二轮没有改善而直接退出。问题按原页和修改位置去重，候选退化时保留之前的 PDF，并继续要求不同的修复方案。达到轮数上限而仍有确认问题时，保存候选和每轮记录后报错，不发布完成版。独立核验已接受的轻微内容错误也必须解决；纯偏好应由核验环节撤回，不能靠严重程度绕过发布条件。

发布口径与“意见是否存在”分开：程序验收阻断项、以及执行器未执行或执行后仍未解决的 major 语义问题阻止发布；minor 意见和执行器受工具限制无法落地的意见写入 `视觉待复核.md`，不再无限期卡住交付。没有实际改动的意见（`before` 与 `after` 相同、替换为空）在审阅阶段直接撤回。`视觉审阅记录.json` 的 `blocking` 和 `advisories` 分别保存两类问题。

参考文献条目保留原文：作者、题名、会议或期刊名、卷期页码和 DOI 不翻译、不音译。`harness/reference_audit.py` 统计参考文献区中仍含中文的条目，写入 `参考文献检查.json` 并以 `质量验收.json` 的 `references` 字段报告；它只提示，不自动改写正文。出现中文条目时应重新翻译该区域，而不是放宽检查。

### 页面版式套话

会议模板印在页面四周的文字（审稿人须知、投稿声明、版权行、页码、页眉）不属于论文内容。`source/page_chrome.py` 按位置和字号识别这些区域：页首 5% 内、字号不超过正文的文字，以及页脚 8% 内明显小于正文的字号或纯页码。翻译前在页面图上把这些区域涂白，文本层回退时也跳过，因此不依赖具体措辞；换成其他会议模板时同样生效。首页大字号标题不在遮挡范围内。

## 检查命令

在工程根目录运行。

```sh
.venv/bin/python -m unittest discover -s tests -q
.venv/bin/python translate.py --help
.venv/bin/python -m paper_translator --help
```

测试包含模拟模型响应，用于验证修复动作、失败恢复、语言判别和排版边界。涉及版式的更改还应真实编译 PDF 并查看页面。真实服务验证需单独报告，不能用模拟响应代替。

## 路径与任务兼容

根目录 `translate.py` 和两个 macOS 启动器保留。Python 内部模块改为 `paper_translator` 包内导入。DeepSeek 本地配置仍从工程根目录读取。任务代码指纹递归覆盖包内 Python 文件，整理前的未完成任务因代码变化需要新建输出目录。

发布成功后 `job_runtime.Job.publish()` 会删除同名 `.job` 工作目录（检查点、请求缓存、中间候选），只留下交付目录；任务失败时保留以便恢复。设置 `PAPER_KEEP_JOB=1` 可保留工作目录用于排查。

## 提交内容

提交源码、测试、依赖清单、启动器和维护文档。虚拟环境、密钥、缓存、任务目录和翻译产物由 `.gitignore` 排除。旧版演示样例已清理。

视觉意见在执行前增加独立证据核验。核验请求明确标记原稿和成品图片，只提供被检查的位置与片段，不转发前一检查者的解释，减少错误结论的诱导。PDF 提取文本只用于定位，不得作为上下标、花体或数学结构的证据。撤回的意见及理由写入每轮记录；有可见异常但证据不足时仍阻断发布。

数值表按原字形基线定位在原生 LaTeX 列中，保留上下标相对于正文的偏移，避免把不同基线当成新的表行。并排图按原稿图注的同一水平位置和不重叠栏宽分组；图注使用原稿图注宽度，不受图片裁片宽度限制。

表格以原稿矢量页整块嵌入，原 PDF 的裁剪路径和隐藏文字随矢量一起保留，不会重新进入文字层。`table_regions()` 只用表题和横线定位区域，不重建单元格。

对 `qwen3-vl` 系列，默认视觉审阅和独立核验显式启用 `enable_thinking=true`，思考预算为 4096 token；其他模型不注入该供应商参数。官方参数说明：https://help.aliyun.com/en/model-studio/vision 。核验状态使用 `confirmed_error`、`no_error`、`insufficient_evidence`，避免把“接受译文”和“接受错误报告”混为一谈。只有真实上轮问题 ID 参与复查，模型虚构的其他 ID 不改变任务状态。

### 结构与资源预处理

- `translation/headings.py` 在渲染前翻译短章节标题，保护首页题头，校验标题编号、数字与数学表达。正文语言检查不能代替这一结构检查。
- `source/contents.py` 将可完整匹配的目录转换为 LaTeX 原生章节链接与页码。任一条目无法匹配时不生成不完整目录，避免沿用原稿页码误导阅读。
- `source/crop_complete.py` 在资源指纹建立前补全图像与图注之间的坐标轴标签区域；采用替换文件而非原位写入，避免污染硬链接缓存。补全后重新建立资源清单和摘要。
- 模型返回 JSON 编码错误时，针对支持结构化输出的千问模型单独执行编码修复，不重新进行视觉判断；修复提示要求保留原有判断和所有字段内容。解析成功后仍执行原有 schema 与动作验证。

视觉核验的成品页集合同时使用正文相似度和原稿对象身份：图、表、算法通过实际 PDF 的命名目标补齐页面，避免重复图注导致漏看对象。独立核验必须覆盖所有意见及上一轮问题；缺项或无效结论带明确字段要求重试，重试耗尽仍阻断交付。

每轮完成程序验收后，先将实际候选和修改决定持久化，再发送视觉请求。`candidate-ready.json` 最后写入，表示候选可恢复。同一任务重试直接读取已保存 PDF，不能重新翻译或渲染该轮；代码或配置改变仍按任务身份校验要求新建任务。相关回归测试验证恢复时渲染器只执行一次。

### 审阅协议与实际渲染证据

视觉审阅与独立核验都接收 `render_evidence`。动态目录的标题和目标页从渲染记录及实际 PDF 命名目标读取，不能使用 Markdown 中的旧目录页码判断成品。未解析出的目标明确记为未知；记录不能替代图像检查。每次排版先删除旧目录记录，避免重用失效证据。

`review_contract` 对空回复、缺字段和非法动作进行最多三次协议恢复，携带原始证据和上次错误要求模型完整重答。恢复耗尽时保留失败，不能当成无问题。独立核验给出的修复动作也须通过枚举校验。接口断连和不完整响应支持有限重试。

### DeepSeek 与续跑验收

默认视觉模型为 `deepseek-flash`，使用 DeepSeek 官方兼容接口，关闭 thinking 并启用 JSON 输出。凭据按服务域名单独读取；DeepSeek 不回退使用其他供应商的密钥。输出截断时停止同参数重试。请求用量写入任务目录，恢复任务不会清零；认证、余额或权限错误停止后续请求。

通过 `--vision-draft` 续跑时同时读取同目录的布局配置、图像与视觉审阅记录。继承记录必须与原稿 SHA-256 一致；未解决事项进入首轮修改与复查，保存在 `继承审阅记录.json`。每轮的 `incoming_decisions` 记录实际应用到本候选的动作；新候选不能继承旧的 candidate-ready 标志或覆盖新轮次的动作记录。

修改定位仅允许唯一精确匹配或空白差异。若模型误报相邻原页，只有原文证据在全文唯一、且译段在该页精确匹配，才纠正归属。原页引用匹配同时考虑 PDF 行末连字符的两种情况：复合词连字符与自动断词；不改变数字和正文词序。

Pandoc 会将紧邻数字的美元符号公式视为普通文本。LaTeX 导出前为带数学命令或上下标的此类公式补充分隔空白，保留公式内容；真实 Pandoc 回归测试覆盖表注数学标记，普通价格文本保持不变。
